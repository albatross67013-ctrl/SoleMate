# SoleMate

A responsive sneaker storefront built with plain HTML, CSS, and JavaScript.

## Run

Open `updated_index.html` in a modern browser. Product, cart, wishlist, and demo order data use browser local storage.

## Checkout

Add products to the cart and choose **Proceed to Checkout**. Enter delivery details, then choose Cash on Delivery or the demo online option. COD creates a local demo order and clears the cart. The online choice is not a live payment; real card or UPI processing requires a payment provider and secure server integration.
